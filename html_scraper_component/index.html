            What do the node types mean?
            

              
1📄DocumentA primary content node — article, report, scraped page, or any standalone text file.

              
2🏷EntityA named real-world thing extracted from content: person, organisation, product, or place.

              
3💡ConceptAn abstract idea, topic, or theme that spans multiple documents.

              
4🗂CategoryA classification bucket or folder grouping that contains other nodes.

              
5🔗ReferenceAn external link or citation pointing to a source outside the graph.

            How the mapping works
            

              
Each folder becomes a 🗂 Category node (type 4).

              Each .md file inside that folder becomes a 📄 Document node (type 1).

              A CONTAINS edge (typeId 1) is created from the Category → each of its Documents.

              Nested sub-folders are resolved to the nearest top-level category.
